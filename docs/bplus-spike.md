# B+ spike：单图描述及中文→西里尔蒙古文验证

本记录包含两个独立阶段：Ollama 单图描述只执行一次；随后将保存的中文描述交给现有 NLLB 环境重跑一次，并保存翻译运行证据。没有实现 `--with-photos`，没有修改现有 CLI，也没有提交商品图片。

## 1. 图片→中文描述

模型：`qwen2.5vl:7b`（Q4_K_M），Ollama `0.40.5`。本地图片由用户提供，已确认无店招、人脸或真实价格标签等敏感内容。图片仅本地使用，不随仓库分发。

固定 prompt 原文：

> 请用不超过50个汉字客观描述图中商品，只描述清晰可见的品类、颜色、图案和外形。不要推断材质、品牌、尺寸、价格、产地或功效。不确定的信息省略，只输出描述正文。

参数：`temperature=0.2`、`num_ctx=4096`、`num_predict=128`、`stream=false`、`keep_alive=0`。图片经 base64 传给本地 `/api/generate`，测试结束已确认模型卸载。

中文输出原文，未经改写：

> 蓝色衬衫，红色和蓝色条纹领带，黑色夹克，胸前有徽章。

- 请求总耗时：**31.423 秒**。
- 模型加载耗时：5.108 秒。
- 图片/提示处理耗时：25.014 秒。
- 输出生成耗时：1.119 秒。
- `done=true`，`done_reason=stop`。
- 输出 21 tokens；22 个汉字，含标点共 26 个字符；未超过 50 汉字，也未触及输出截断。

**第一阶段结论：** 本图人工目检反馈为“22 个汉字，未发现编造”，单图验证通过。这是用户/Muse 对这一张图片的目检结论，不是自动判定，也不能证明其他图片上的描述普遍可靠。

## 2. 中文描述→西里尔蒙古文

为补齐此前只保留在聊天中的译文证据，使用现有独立脚本 `/Volumes/data/NLLB/translate.py` 重跑一次；没有重新调用视觉模型。输入逐字读取第一阶段保存的 `description.txt`。

模型：`facebook/nllb-200-3.3B`，方向 `zho_Hans` → `khk_Cyrl`，本地离线运行，MPS、FP16。沿用此前独立翻译测试参数：`num_beams=4`、`max_new_tokens=256`、`do_sample=false`。这里记录的是独立脚本的实际参数，不能混同为商户 CLI 的 `max_length=256`。

输入中文原文：

> 蓝色衬衫，红色和蓝色条纹领带，黑色夹克，胸前有徽章。

输出蒙古文原文，未经人工修订：

> Цэнхэр хувцас, улаан, цэнхэр шугаман галзуу, хар өмсөгч, цээж дээр тэмдэгтэй.

- 独立脚本报告的翻译调用耗时：**2.91 秒**。
- 进程总耗时（包括启动、导入和模型加载等）：35.647 秒；没有单独测量 NLLB 加载耗时。
- 退出码：0；`output_limit_reached=false`。
- 蒙文与此前聊天中返回的首次译文完全一致。独立脚本未记录原始 token ID 或 NLLB 的 `done_reason`，不以视觉阶段的指标替代。

**第二阶段结论：** 译文有关键商品术语错误，需要人工修订。复核反馈指出“领带”位置出现 `галзуу`、“夹克”位置出现 `өмсөгч`；这些并非目标服装名称的可靠表达。“胸前有徽章”对应片段被复核者认为基本符合原意，但不能据此认定整句准确，也不使用“仅这一处正确”的绝对结论。

两段实验表明：图像描述链路可运行，后续翻译的关键术语仍会失真；第一阶段通过不意味着整条链路可直接发布。本次只做本地非商业原型验证，NLLB 权重仍受 CC-BY-NC 4.0 许可约束。
